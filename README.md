# passive-income-youtube-thumbnail

ouTube Thumbnail Design – Passive Income



📌 Project Overview

A bold and engaging YouTube thumbnail designed for a video about 7 Passive Income Ideas. The goal was to create a high-impact visual that communicates the topic instantly and encourages viewers to click.

🎨 Design Highlights

Strong and attention-grabbing headline: “7 PASSIVE INCOME IDEAS”

High-contrast typography for easy readability

Financial-themed visuals including coins, money bag, and growth chart

Human reaction element to increase visual engagement

Green, yellow, black, and white color combination for a bold financial theme

Clear visual hierarchy designed for YouTube's thumbnail format

Income ideas represented with recognizable platform/category icons

🛠️ Tools Used

Canva

Adobe Photoshop

🎯 Design Objective

The thumbnail was created to:

Grab attention in a competitive YouTube feed

Communicate the video topic within seconds

Create curiosity around the 7 passive income methods

Maintain strong readability on both desktop and mobile screens
